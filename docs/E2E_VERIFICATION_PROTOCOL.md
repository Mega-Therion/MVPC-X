# MVPC-X End-to-End Verification Protocol

This document defines the intended end-to-end path from a human/AI claim to a reproducible, machine-checkable witness.

```text
human/AI intent
  -> claim manifest
  -> formalization binding
  -> semantic review/tests
  -> verification plan
  -> parallel prover/computation checks
  -> evidence graph
  -> assurance derivation
  -> sealed witness
  -> independent offline verification
```

Every authoritative result must bind the natural claim to the exact formal proposition and checked artifact. A proof of a different proposition is not evidence for the original claim.
